## 为什么是 Rust

我喜欢 Rust 的一点是:编译器像一个严格但善良的同事,在运行前就把大部分问题挡在门外。

```rust
#[derive(Debug)]
struct Note {
    title: String,
    tags: Vec<String>,
}

fn main() {
    let first = Note {
        title: String::from("用 Rust 的方式,给博客写个开篇"),
        tags: vec!["Rust".into(), "博客".into()],
    };
    println!("{first:?}");
}
```

所有权和借用检查一开始会让人头大,但一旦习惯,那种「编译通过 ≈ 基本能跑」的安心感很难回去。
