## 关于这个博客

博客基于 [Rspress](https://rspress.rs/) 搭建,主题是自己动手定制的:
粉色配色 + 等宽字体 + 终端窗口,整站像一台你自己的终端。文章列表会自动读取 `date` / `tags` frontmatter,
每写一篇带日期的笔记就会自动出现在 [博客](/posts/) 列表里。

写作原则很简单:**把思考编译成文字**。能讲清楚才算真的学会。
